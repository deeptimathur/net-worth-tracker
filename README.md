# Net Worth Tracker

A multi-user web app for tracking net worth across countries. It supports India and the USA today and is built so more countries can be added as plug-ins.

- Sign up with email or Google, link US banks, cards and brokerages through Plaid, or add bank, brokerage, mutual fund, retirement, loan and card accounts in either country.
- See net worth in USD and INR with daily ECB exchange rates, plus a by-country breakdown.
- Track history month by month and see growth against US and India inflation.
- Import Indian demat and mutual fund values from a password-protected CDSL / NSDL CAS PDF, with a review step before saving.
- Balances are encrypted per user before they reach the database.

See [docs/PLAN.md](docs/PLAN.md) for architecture, the security model and the roadmap.

## Running locally

Requires Node 20+ and Postgres.

```bash
npm install
cp .env.example .env.local      # then fill in DATABASE_URL and APP_ENCRYPTION_KEY
npm run db:migrate
npm run dev
```

Generate an encryption key with:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Keep it in your host's secret store. Losing it makes stored balances unreadable.

## Tests

```bash
npm test          # unit tests, including a synthetic encrypted CAS PDF
npm run lint      # type check
```

The CAS fixture in `tests/fixtures/` is synthetic and generated by `scripts/make-cas-fixture.py`. Never commit a real statement.

## Adding a country

1. Create `src/lib/countries/<code>.ts` exporting a `CountryModule` (currency, locale, account types, institutions, yearly CPI inflation, importers).
2. Register it in `src/lib/countries/index.ts`.

Totals, forms and FX pick it up automatically. Country-specific importers go under `src/lib/importers/`.
